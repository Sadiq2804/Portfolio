## 🎬 Getting Started (3 Steps)

### Step 1: Local Setup (5 minutes)
```bash
cd portfolio
npm install
npm run dev
# Open http://localhost:3000
```

### Step 2: Customize (10 minutes)
- Edit component files with your content
- Update links to your GitHub repos
- Customize colors in `tailwind.config.js` (optional)

### Step 3: Deploy (15 minutes)
```bash
# Push to GitHub
git add .
git commit -m "Initial portfolio"
git push origin main

# Deploy on Vercel
# → Go to vercel.com → Import GitHub repo → Deploy
# → Add custom domain sadiq.ai → Done!
```

**Total time to live:** ~30 minutes

`components/Projects.jsx` → Add to `projects` array

### To Update Skills:
`components/Skills.jsx` → Edit `skillCategories`

`styles/globals.css` → Update font imports

### To Customize Theme:
`tailwind.config.js` → Modify `extend` object

## 📞 Support Resources

| Issue | Solution |
|-------|----------|
| **Build fails** | Check `npm run build` locally, check dependencies |
| **Styling broken** | Hard refresh (Ctrl+Shift+R), clear `.next` folder |
| **Domain not working** | Check DNS records, wait 24-48 hours |
| **Links not working** | Verify GitHub URLs are public, test manually |
| **Dark mode issues** | Clear cache, check browser theme settings |
